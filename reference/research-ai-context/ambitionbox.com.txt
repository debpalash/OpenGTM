## Overview

AmbitionBox is India's largest employer review platform (similar to Glassdoor).
It covers 6L+ (600K+) companies with employee-submitted reviews, salaries,
interview questions, and benefits data. The site runs on Next.js with a rich
internal REST API gateway at `/servicegateway-ambitionbox/`.

**Why it matters for lead gen**: Provides company size, industry classification,
headquarters, employee ratings, hiring activity, and salary data — enrichment
signals impossible to get from MCA or Google Maps.

## Data Coverage

- 600K+ companies across all Indian industries
- 4,096 recruitment companies alone
- Employee reviews, salary ranges, interview questions
- Company ratings (overall + 5 sub-categories)
- Office locations with city-level data
- Active job listings from Naukri.com integration
- Company comparisons and competitor graphs

## URL Structure

### Listing Pages (paginated company discovery)

```
/list-of-companies                              → All companies, paginated
/{industry}-companies-in-india                  → Industry-specific listing
/companies-in-{city}                            → City-specific listing

# Examples:
/recruitment-companies-in-india                 → 4,096 recruitment companies
/it-services-and-consulting-companies-in-india  → IT services
/financial-services-companies-in-india          → Finance
/companies-in-bengaluru                         → Bangalore companies
/companies-in-mumbai                            → Mumbai companies
```

### Company Detail Pages

```
/overview/{slug}-overview                       → Company overview (main profile)
/reviews/{slug}-reviews                         → Employee reviews
/salaries/{slug}-salaries                       → Salary data
/interviews/{slug}-interview-questions          → Interview questions
/jobs/{slug}-jobs-cmp                           → Job listings
/benefits/{slug}-benefits                       → Employee benefits
/photos/{slug}-photos                           → Office photos
/overview/{slug}-overview/locations             → Office locations
/overview/{slug}-overview/locations/{city}-offices → City-specific office
```

### Slug Convention
Company name → lowercase, hyphenated:
  `Quess` → `quess`
  `TeamLease Services` → `team-lease`
  `Collabera Talent Solutions` → `collabera-talent-solutions`

## Internal JSON API (servicegateway)

Base: `https://www.ambitionbox.com/servicegateway-ambitionbox/`

### Company Listing Search (PRIMARY for bulk discovery)
```
POST /company-services/v0/listing/filters/search
Content-Type: application/json

{
  "isFilterApplied": true,
  "limit": 20,
  "page": 1,
  "sortBy": "popular",        // or null
  "type": "all",
  "industries": ["recruitment"]  // optional filter
}

Response: Company list with IDs, names, ratings, review/salary counts
```

### Company Basic Details
```
POST /company-services/v0/company/basic-details
Content-Type: application/json

Response: Full company profile — name, website, HQ, industry, founded year,
          employee count, revenue, company type
```

### Company Locations
```
GET /company-services/v0/company/{companyId}/sectionalDetails?sections=companyLocations
Response: All office locations with city/state
```

### Salary Data
```
GET /salaries-services/v0/company/{companyId}/jobProfile/{profileId}/salaryData
Response: Min/max/avg CTC for specific job profiles
```

### Review Data
```
GET /review-services/v0/review/data/{companyId}?page=1&limit=8
Response: Employee reviews with ratings, job titles, departments
```

### Rating Distribution
```
GET /review-services/v0/review/distribution/{companyId}
Response: Rating breakdown (1-5 star distribution)
```

### Rating Trends
```
GET /review-services/v0/employer/static-rating-trend/{companyId}
Response: Historical rating trends with competitor comparisons
```

### Jobs
```
GET /jobs-services/v0/jobs/filters/company/{companyId}
Response: Active job listings (from Naukri.com)
```

### Company Comparisons
```
GET /company-services/v0/compare/company/top-comparsions/{companyId}
Response: Top competitor companies with comparison data
```

### Company Collections (sidebar interlinking)
```
POST /company-services/v0/company-collections/interlinking-widget
POST /company-services/v0/listing/dream/companies/search
GET  /company-services/v0/company-collections/filters/search
Response: Related companies, filter options, dream companies list
```

## Scraping Strategy

### Recommended Approach: Hybrid (SSR HTML + JSON API)

1. **Bulk discovery**: Use the listing API POST endpoint to enumerate companies
   by industry. Paginate through `page=1..N` with `limit=20`.
2. **Company enrichment**: Fetch `/overview/{slug}-overview` SSR pages for
   rich profile data. Parse the structured text sections.
3. **Deep enrichment**: Hit individual API endpoints for salary, review,
   and job data per company ID.

### Authentication
- No auth required for read endpoints
- `accept: application/json` header is sufficient
- Cookie-based session optional (not required)

### Rate Limiting
- Site is behind CloudFlare
- Recommended: 0.5-1 req/sec with randomized delays
- Use stealth HTTP headers (curl-cffi or similar)

### Company ID Discovery
Company IDs are embedded in URLs and API calls:
- Quess = 14207
- Samsung = 89
- Extract from listing API response or URL patterns
