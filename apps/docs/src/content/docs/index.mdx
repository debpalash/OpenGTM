<section class="lp-section lp-setup" id="install">
  <header class="lp-section__head">
    <p class="lp-kicker">START HERE</p>
    <h2>Install with Docker Compose.</h2>
    <p>The installer creates admin credentials, secrets, and a writable data directory.</p>
  </header>
  <div class="lp-setup__grid">
    <div class="lp-setup__path">
      <p class="lp-setup__label"><span>01 / LAPTOP</span><span>Docker Compose · macOS / Linux</span></p>

```bash wrap
git clone https://github.com/debpalash/OpenGTM.git
cd OpenGTM
./scripts/install.sh
```

      <p>Open <code>localhost:3000</code>. Read the initial admin password from <code>.opengtm-initial-credentials</code>.</p>
    </div>
    <div class="lp-setup__path">
      <p class="lp-setup__label"><span>02 / SERVER</span><span>Versioned image · private HTTP</span></p>

```bash wrap
git clone --branch v3.0.0 https://github.com/debpalash/OpenGTM.git
cd OpenGTM
./scripts/install.sh --no-start
```

      <p>Pin the image, bind port 3000 to loopback, and put a TLS proxy in front. <a href="/getting-started/quickstart/#server">Server install steps →</a></p>
    </div>
  </div>
  <p class="lp-setup__foot">Docker Compose v2 · about 4 GB free RAM. <a href="/getting-started/quickstart/">Installation guide</a> · <a href="/self-hosting/production/">Production checklist</a> · <a href="/compare/clay-alternative/">OpenGTM vs. Clay</a></p>
</section>
