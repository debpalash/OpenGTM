<section class="lp-section lp-setup" id="install">
  <header class="lp-section__head">
    <p class="lp-kicker">START HERE</p>
    <h2>From clone to workspace.</h2>
    <p>One installer creates unique local secrets and a writable data directory. Pick the path that matches where you run it.</p>
  </header>
  <div class="lp-setup__grid">
    <div class="lp-setup__path">
      <p class="lp-setup__label"><span>01 / LAPTOP</span><span>Docker Compose · macOS / Linux</span></p>

```bash wrap
git clone https://github.com/debpalash/OpenGTM.git
cd OpenGTM
./scripts/install.sh
```

      <p>Open <code>localhost:3000</code>. Your first password is in <code>.opengtm-initial-credentials</code>.</p>
    </div>
    <div class="lp-setup__path">
      <p class="lp-setup__label"><span>02 / SERVER</span><span>Versioned image · private HTTP</span></p>

```bash wrap
git clone --branch v3.0.0 https://github.com/debpalash/OpenGTM.git
cd OpenGTM
./scripts/install.sh --no-start
```

      <p>Pin the GHCR image, bind HTTP to loopback, then add TLS. <a href="/getting-started/quickstart/#server">Finish server setup →</a></p>
    </div>
  </div>
  <p class="lp-setup__foot">Docker with Compose v2 and about 4 GB RAM. <a href="/getting-started/quickstart/">Full quickstart</a> · <a href="/self-hosting/production/">Production checklist</a></p>
</section>
