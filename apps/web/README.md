# OpenGTM web app

React 19 + TypeScript + Vite + Tailwind 4 + shadcn/ui frontend for OpenGTM.

```bash
bun install
bun run dev        # stable https://opengtm.localhost via Portless
bun run dev:app    # plain Vite dev server on :5173
bun run build      # tsc -b && vite build → dist/
bun run lint
bun run check:bundle   # initial-JS budget (after a build)
bun run check:api      # the typed /api/v2 client matches the OpenAPI contract
bun run gen:api        # regenerate it
```

### Typed client for the Go API

`src/lib/api-v2` is a typed client for the Go server's `/api/v2` routes.
`schema.ts` is generated by `openapi-typescript` from
[`packages/contracts/openapi.v2.yaml`](../../packages/contracts/openapi.v2.yaml)
and committed; `client.ts` is a small `fetch` wrapper that checks the path,
path parameters, query and body against it:

```ts
const page = await apiV2("get", "/api/v2/plugin-runs", { query: { limit: 50, cursor } })
const run = await apiV2("get", "/api/v2/plugin-runs/{id}", { path: { id } })
```

Edit the YAML when an endpoint changes, run `bun run gen:api`, commit both.
CI runs `check:api` and fails on a stale `schema.ts`; the Go server's tests fail
when served responses stop matching the YAML.

The app talks to the FastAPI backend (default `http://localhost:8000`, or the
nginx front on `:3000` in Docker Compose). See the root
[README](../../README.md) and https://opengtm.palash.dev for the full setup.
